# Dynasty Plebs

League-history archive for Dynasty Plebs, covering the completed 2019–2025 seasons.

## Data

- 2019–2023: ESPN standings screenshots
- 2024–2025: Sleeper standings / playoff data
- Tracks regular-season W-L record, points for, points against, team name, manager/handle, rookie draft results, and displayed standings order.
- ESPN screenshots were captured from Final Standings; Sleeper screenshots show League Standings. The site deliberately does not treat those rank columns as one uniform championship metric.

## Legacy Score

Dynasty Plebs uses the same locked formula as Fantasy Ranch:

`Legacy Score = Reg Season Win % × (1 + 0.05 × Service Time + 0.05 × Playoff Wins + 0.50 × Championships) × 1000`

Playoff bye weeks count as playoff wins.

## Identity rule

Sleeper handles are merged into earlier ESPN manager identities only when the supplied history makes the match clear. Unknown handles remain separate rather than being guessed.

## App

Static, dependency-free HTML/CSS/JS. Open `index.html` directly or deploy the repository to Vercel as a static site.
